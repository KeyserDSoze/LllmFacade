# LllmFacade

Workspace multi-interfaccia per organizzare progetti e conversazioni AI.

Il progetto parte da una POC composta da dashboard GitHub Pages, estensione Chrome e desktop Chromium/Electron. Struttura e convenzioni ispirate a `KeyserDSoze/DeliveryManager`.

> Sviluppo in corso. Vedi il branch di bootstrap per codice, test e documentazione.
